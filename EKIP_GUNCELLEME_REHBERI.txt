1) BACKEND GUNCELLEME (PYTHON 3.12)
--------------------------------------------------------------------------------

Neden 3.12?
- Proje bagimliliklari (ozellikle numpy/face-recognition zinciri) icin en stabil
  ve sorunsuz surum 3.12'dir.

1. Python 3.12 kurulu mu kontrol:
   py -0p
   Listede 3.12 yoksa:
   winget install -e --id Python.Python.3.12 --accept-package-agreements --accept-source-agreements

2. Proje icinde 3.12 venv olustur:
   py -3.12 -m venv .venv312

3. Venv aktive et:
   .\.venv312\Scripts\Activate.ps1

4. Pip guncelle:
   python -m pip install --upgrade pip

5. Backend paketlerini kur:
   python -m pip install -r requirements.txt

NOT (Yuz tanima paketi):
- Windows'ta face-recognition/dlib bazen CMake ve Build Tools ister.
- Bu paket kurulmadiysa bile backend acilabilir; yuz tanima ozelligi devre disi kalir.
- Proje acilisi icin kritik olan Flask/JWT/CORS vb. paketlerin kurulmasidir.

--------------------------------------------------------------------------------
2) WEB PANEL GUNCELLEME
--------------------------------------------------------------------------------

1. Dizin degistir:
   cd web-panel

2. Paket kur:
   npm install

3. Gelistirme modunda calistir:
   npm start

4. Build dogrulamasi (onerilen):
   npm run build

NOT:
- Source-map warning'leri CRACO ile filtrelenmistir.
- API URL ortami icin ornek:
  web-panel\.env.example

--------------------------------------------------------------------------------
3) MOBILE APP GUNCELLEME (EXPO)
--------------------------------------------------------------------------------

1. Dizin degistir:
   cd ..\mobile-app

2. Paket kur:
   npm install

3. Expo uyumluluk kontrolu:
   npx expo-doctor
   Beklenen: "No issues detected"

4. Uygulamayi baslat:
   npx expo start

API URL:
- Mobile tarafinda EXPO_PUBLIC_API_URL kullanilir.
- Gerekiyorsa .env icine tanimlayin:
  EXPO_PUBLIC_API_URL=http://<BILGISAYAR_IP>:5000

--------------------------------------------------------------------------------
4) SISTEMI BIRLIKTE CALISTIRMA (EN KRITIK BOLUM)
--------------------------------------------------------------------------------

1. Terminal A (Backend):

2. Saglik kontrolu:

4. Terminal C (Mobile):

--------------------------------------------------------------------------------
5) YAYGIN HATALAR VE HIZLI COZUMLER
--------------------------------------------------------------------------------

[HATA] ModuleNotFoundError: No module named 'flask'
COZUM:
- Dogru venv aktif degil veya paketler kurulmamis.
- Su adimlari tekrar yapin:
  .\.venv312\Scripts\Activate.ps1
  python -m pip install -r requirements.txt

[HATA] ECONNREFUSED (web -> localhost:5000)
COZUM:
- Backend kapali.
- python app.py ile backend'i acin.

[HATA] npm install peer dependency sorunlari (mobile)
COZUM:
- Node modules temizleyip tekrar kurun:
  rd /s /q node_modules
  del package-lock.json
  npm install
  npx expo-doctor

[HATA] face-recognition/dlib build hatasi
COZUM:
- Bu ozellik icin CMake + Visual C++ Build Tools gerekir.
- Kritik degilse backend'i bu ozellik olmadan calistirin.
