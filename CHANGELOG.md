# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2024-10-21

### ✨ Added
- **Tailwind CSS 3** integration for Web Panel
- **NativeWind 2** integration for Mobile App
- Unified styling approach across platforms
- Custom color palette (primary, success, danger, etc.)

### 🎨 Changed
- Migrated all web components from CSS Modules to Tailwind utility classes
- Migrated all mobile components from StyleSheet to NativeWind classes
- Improved UI consistency across web and mobile
- Enhanced responsive design with Tailwind breakpoints

### 🗑️ Removed
- All CSS Module files (*.module.css)
- StyleSheet definitions from mobile components

### 📝 Updated
- Web Panel README with Tailwind documentation
- Mobile App README with NativeWind documentation
- Main README with technology stack updates

## [1.0.0] - 2024-10-21

### 🎉 Initial Release
- Full-stack smart attendance system
- Supabase backend with PostgreSQL
- React Native mobile app for students
- React web panel for teachers and admins
- Multi-layer verification (QR, GPS, Face, Device)
- Row Level Security (RLS)
- Face recognition with Azure Face API
- Real-time attendance tracking
- Comprehensive reporting system
- User management (Admin only)
- KVKK/GDPR compliant
- Complete documentation
