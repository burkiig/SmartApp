[2] BACKEND — geofence_service.py GÜVENLİK YÜKSELTMESİ
    ─────────────────────────────────────────────────────
    Sorun   : detect_fake_gps() fonksiyonu None değerlerinde crash edebiliyordu
              ve bazı önemli heuristik kontroller eksikti.

    Eklenenler:
      • None guard'ları: accuracy, altitude, speed için tüm kontrollerde
        "if x is not None and ..." pattern'i uygulandı.
      • Yeni kontrol — too_precise_gps:
          if accuracy is not None and 0 < accuracy < 5:
              flag("too_precise_gps")
          Gerçek GPS binalarda 5-30m sapma verir; 5m altı mock GPS imzasıdır.
      • Yeni kontrol — suspicious_altitude:
          if altitude is not None and altitude == 0.0:
              flag("suspicious_altitude")
          Mock GPS uygulamaları altitude üretmez, sıfır gönderir.
      • speed normalizasyonu: iOS'ta speed < 0 (unavailable) olabilir;
          speed if (speed >= 0) else None pattern'i uygulandı.
      • Yeni fonksiyon — detect_location_jump():
          İki ardışık GPS fix arasında fiziksel olarak imkânsız hız tespiti.
          attendance_engine entegrasyonu için hazır (ileride step state'e
          önceki koordinatlar eklenirse aktive edilebilir).
      • Yeni parametre: altitude, prev_location, gps_timestamp
          Hepsinde None varsayılan değer — geriye dönük uyumlu.

[7] MOBİL — locationService.js TAM GPS PAYLOAD
    ─────────────────────────────────────────────────────
    Sorun   : Backend'e gönderilen payload sadece lat/lng içeriyordu.
              Fake GPS heuristikleri için gerekli olan altitude, speed,
              mocked ve gps_timestamp alanları eksikti.

    Değişiklikler:
      • getCurrentLocation() artık ham Location nesnesini döndürüyor
        (önceki versiyon sadece {lat, lng, accuracy} döndürüyordu).
      • normalizeSpeed() yardımcı fonksiyon eklendi:
          iOS'ta speed < 0 → null (unavailable sinyali).
      • verifyLocation() payload'a eklenenler:
          altitude    : coords.altitude ?? null
          speed       : normalizeSpeed(coords.speed)
          gps_timestamp: new Date(location.timestamp).toISOString()
          mocked      : location.mocked ?? false  (Expo SDK 48+)
      • JSDoc güncellendi — döndürülen alanlar belgelendi.
